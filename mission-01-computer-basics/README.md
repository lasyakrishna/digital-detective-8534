### Task 1.1 — Trace one activity using IPOS
**Chosen Activity:** Searching for a topic on the internet.

| stage | what happens in your example? | Possible hardware / component |
| :---| :---| :---|
| **Input** | I typed a search query "how computers work? " into the browser search bar and press Enter | Keyboard, mouse |
| **Processing** | The CPU processes the keystrokes, and the browser sends the request over the internet to fetch and organize matching search results | CPU / processor and memory |
| **Output** | The list of matching web links, images, and summaries is displayed visually for me to read | Screen / monitor |
| **storage** | The browser saves the search term in my browsing history and caches webpage data for faster loading later | SSD, hard disk or cloud storage |


* **Data Flow Explanation:** When I type a query on the keyboard, those electrical signals are sent to the CPU as input. The processor and RAM work with the web browser to request data from the internet and render the webpage. Once processed, the final visual page is sent to the monitor as output, while a record of the visit is saved onto the SSD in the browser's history for future reference

## 4. My understanding
* Every computing device follows the IPOS cycle to turn raw user input into useful output and saved data.
* Hardware refers to physical components you can touch, while software gives hardware instructions on what to do.
* Software is divided into operating systems (which manage resources), applications (for user tasks), and utilities (for system maintenance).
* Everyday machines like ATMs and microwave ovens are specialized computer systems with clear inputs and outputs.
