## Topics Explored

* **Computer Architecture & IPOS:** Input, Processing, Output, and Storage cycles, hardware vs. software classification, and real-world computer systems.
* **Command-Line Interface (CLI):** Navigating directories, managing files safely, command flags (`-lah`), pipes (`|`), and package managers.
* **Operating Systems:** OS responsibilities, active processes and PIDs, absolute vs. relative paths, and file permissions (`rwx`).
* **Program Execution:** Running Python 3 scripts and comparing compilers vs. interpreters.
* **Data Representation:** Binary, decimal, and hexadecimal conversions, plus ASCII and UTF-8 character encoding.
* **Version Control & Collaboration:** Git staging, committing, branching (`update-about`), and Pull Requests on GitHub.
* **Computer Networking:** LAN/MAN/WAN, DNS, routers, protocols, packet switching, client-server architecture, and webpage request lifecycles.

## How to Run the Number Converter (`Mission 5`)

1. Open Terminal and navigate into the Mission 5 folder:
   ```bash
   cd mission-05-numbers-data
   ```
2. Run the Python converter script using Python 3:
   ```bash
   python3 number_converter.py
   ```
3. Enter any positive decimal integer when prompted (for example, `25`) to view its binary (`0b11001`) and hexadecimal (`0x19`) representations.
