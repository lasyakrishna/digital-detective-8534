## 3. Commands / tools used
* `python3 --version` : Checks the installed Python version (Python 3.14.7).
* `git --version` : Checks the installed Git version (Git 2.50.1).
* `pwd` : Displays the current working directory.
* `cd` : Moves from one directory to another.
* `ls` : Displays files and folders.
* `mkdir` : Creates folders.
* `touch` : Creates an empty file.
* `git init` : Initializes a local Git repository.
* `git add` : Stages changes for a commit.
* `git commit` : Saves changes in Git history.
* `git push` : Uploads committed changes to GitHub.
* VS Code : Used to create and edit project files.
